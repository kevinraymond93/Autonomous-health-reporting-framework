# Autonomous health reporting framework (target - I2C)
-------------------------------------------------------------------------------------
## TEAM 13 - ELEVIUM VLSI PROJECT
-------------------------------------------------------------------------------------
### Problem Statement
Design a framework that periodically gathers operational health information from
multiple subsystems and stores historical records for system-level analysis.

### Core Blocks
- FSM
- SCL Generator
- Shift Registers
- Counters
- FIFO
- CDC
- Memory
- Address Decoder
- ACK Logic

### Objective:
Design and verify a framework that periodically gathers operational health and
status information from multiple subsystems, stores historical records in memory,
and maintains synchronized health reports for system-level monitoring and
analysis. The system shall ensure reliable data collection, transfer,
